# Data Directory

This directory stores the inputs, intermediate files, and outputs of the literature data-extraction workflow.

## Directory structure

| Directory | Description |
|---|---|
| `PDFs/` | Original literature PDF files supplied by the user. |
| `Data_split/` | Five-page PDF sections generated from the original articles, together with intermediate extraction files. |
| `Processed_Results/` | Structured CSV files generated by the extraction, unit-standardization, and name-classification steps. |

## PDF availability

The original articles in `PDFs/` and the derived PDF sections in `Data_split/` are not distributed with this repository because publisher PDFs may be subject to copyright and redistribution restrictions.

To reproduce the workflow, obtain the required articles through lawful institutional or open-access sources and place the PDF files in:

```text
Data/PDFs/
```

The filenames may use DOI-based names, for example:

```text
10.1002_example.12345.pdf
```

Running the main pipeline will split the source articles into five-page sections and recreate the intermediate files in `Data/Data_split/`:

```bash
python pipeline_main.py
```

The final processed tables are written to `Data/Processed_Results/`. Input and output paths can be changed in `pipeline_config.json`.
